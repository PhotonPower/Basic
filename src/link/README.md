# src/link

Quelltext-Linker: liest die Kopfzeilen der Runtime-Module (`;! provides/requires/group/section`),
bildet die transitive Hülle, prüft Gruppen und Label-Hygiene, fügt Startcode, Programm, Runtime, Daten
und BSS zu einem Assembler-Quelltext zusammen und schreibt die Map-Datei.
Siehe [docs/runtime.md](../../docs/runtime.md#linken). Noch leer (Meilenstein 0.4).
